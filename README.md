# Работа с заказом

1. Главное меню → «Заказы» → кнопка «Создать».
2. Выбрать клиента из списка или добавить нового (кнопка «+»).
3. Выбрать инструмент. Если инструмент отсутствует — создать через кнопку «Новый инструмент».
4. В таблице «Услуги» нажать «Добавить» → выбрать тип ремонта → указать цену и мастера.
5. Система автоматически посчитает итоговую стоимость и долю каждого мастера.
6. Нажать «Сохранить» → заказ получает статус «Принят».
7. После выполнения работ — статус сменить на «Готов», затем на «Выдан».
